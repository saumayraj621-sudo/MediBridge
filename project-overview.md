# Project Overview

## Problem

Healthcare referrals between rural clinics, doctors and hospitals
can be difficult to track and manage using disconnected systems.

## Solution

MediBridge provides a centralized digital platform for managing:

- Patients
- Referrals
- Doctors
- Healthcare facilities
- Referral status
- Administrative activity

## Target Users

- Rural Clinics
- Doctors
- District Hospitals
- Administrators
- Healthcare workers
