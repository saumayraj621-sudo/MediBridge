# 🌉 MediBridge Connect

### Unified Health Referral & Rural Outreach Platform

MediBridge Connect is a digital healthcare referral platform designed
to connect rural clinics, hospitals, doctors and administrative teams
through a unified system.

## 🚀 Project

MediBridge provides:

- 👨‍⚕️ Clinic Portal
- 🏥 Doctor Portal
- 📊 Admin Dashboard
- 🧾 Patient Registration
- 🔄 Referral Tracking
- 🤖 AI-powered MediBot
- 🗺️ Nearby Healthcare Facility Discovery
- 📍 Interactive Maps
- 📈 Analytics

## 🛠️ Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite
- Firebase
- Leaflet
- Google Maps
- Google Gemini
